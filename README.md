# AI Creative Studio

استوديو إبداعي عربي أولًا بالذكاء الاصطناعي. - **المرحلة الأولى**: الأساس + أول مسار MVP (مشروع جديد ← فكرة/نص ← نص ← مشاهد ← لوحة قصة قابلة للتعديل).
- **المرحلة الثانية**: مكتبة الشخصيات مع قفل الشخصية وصورها المرجعية، ربط الشخصيات بالمشاهد (تلقائيًا بالاسم أو يدويًا)،
  ذاكرة المشاهد (الملابس وما تحمله الشخصية وتغيّر المظهر تستمر للمشاهد التالية)، دمج كل ذلك في وصف الصورة، وتحرير اللقطات.

- **المرحلة الثالثة**: تثبيت هوية الشخصية (الصورة الرئيسية وصور الوجه والملابس والوضعية، والأزياء المحفوظة وتثبيتها على مجموعة مشاهد)،
  تثبيت الصوت (المزوّد، Voice ID، اللغة، اللهجة، النبرة، السرعة، الطبقة، الأسلوب)، قاعدة معرفة لكل شخصية،
  الصورة المتحدثة (`/talking-photo`)، الشخصية المحاورة التي تجيب من معرفتها فقط وتعيد الحديث بلطف إن خرج السؤال عن موضوعها،
  المشغّل التفاعلي (`/play/[id]`) مع «اسأل الشخصية» داخل الإطار، وضع اختبار الشخصية (`/characters/[id]/test`)،
  مصفوفة دعم المزوّدات (`/providers`)، وتصدير فيديو مسودة MP4 بترجمة عربية مدمجة ولوحة قصة للطباعة/PDF.

- **المرحلة الرابعة**: حركة كاميرا محلية، صوت لكل مشهد وموسيقى، هوية العلامة، إعادة تأطير لكل المنصات (إنستغرام/يوتيوب/فيسبوك/تيك توك)،
  شورتس من الفيديو الطويل، استوديو السوشيال (Hooks وCTA ومناطق آمنة وتصدير متعدد)، المخرج الآلي، الخط الزمني،
  الفيديو التفاعلي (أسئلة، تفرّع، نقاط تفاعلية، ضوابط المنشئ، ردود آمنة)، قاموس النطق، معاينة الصوت، الحساب والاستخدام والخطط (دون دفع).

الحالة التفصيلية ونقطة الاستئناف في [STATUS.md](STATUS.md).

كله محلي ومجاني وبمزوّدات وهمية. الصوت الوهمي نغمات بإيقاع الجملة لا كلام، والشخصية المتحدثة الوهمية تعرض الصورة الأصلية كما هي مع الصوت
دون تحريك الشفاه؛ الكلام الحقيقي ومزامنة الشفاه تحتاج مزوّدًا يُضاف بموافقة صريحة. يتطلب التصدير والصورة المتحدثة وجود FFmpeg على الجهاز.

## التشغيل

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # اختبارات الوحدة والتكامل (Postgres في الذاكرة)
npm run typecheck
npm run worker     # عامل المهام (أوقف التطبيق أولًا عند استخدام PGlite المحلي)
```

لا يحتاج أي مفتاح API ولا خادم قاعدة بيانات: PostgreSQL حقيقي يعمل داخل العملية عبر PGlite ويُحفظ في `.data/`.
المخطط `src/db/migrations/001_init.sql` هو SQL خالص لـPostgres يعمل كما هو على Supabase لاحقًا.

## البنية

```
src/
  config/       إعدادات المنصات (platform-presets) ونقاط البداية بحالتها الصادقة (start-options)
  db/           عميل قاعدة البيانات + الترحيلات (SQL خالص)
  providers/    واجهات المزوّدين: نص، صورة، فيديو، صوت، تحويل كلام، مزامنة شفاه، موسيقى
    mock/       مزوّد وهمي لكل واجهة، بلا شبكة ولا تكلفة
    registry.ts الموجّه: يختار المزوّد حسب القدرة ودرجة الجودة
  lib/          المشاريع، المشاهد، الشخصيات، ذاكرة المشاهد، بناء وصف الصورة، الأصول، طابور المهام، سجل التكلفة
  app/          واجهة Next.js عربية RTL + server actions + مسار تقديم الأصول
scripts/worker.ts  عامل طابور المهام
tests/          اختبارات Vitest
```

## مبادئ

- كل توليد مهمة مستقلة في Postgres، تُعاد وحدها عند الفشل، والمدخلات المتطابقة يُعاد استخدام نتيجتها دون تكلفة.
- كل استدعاء مزوّد (حتى الوهمي) يُسجَّل في `provider_calls` بكميته وسعره.
- كل زر غير منفّذ معطّل ويحمل «قريبًا» أو «يحتاج مزوّدًا».
- إضافة مزوّد حقيقي = ملف محوّل واحد + سطر في `registry.ts`، وبعد موافقة صريحة فقط.

## التراخيص

Next.js وReact وTailwind وVitest وtsx: MIT. PGlite: Apache-2.0. كلها تسمح بالاستخدام التجاري.
FFmpeg يُشغَّل كبرنامج منفصل ولا يُدمج في الكود. الخط DejaVu Sans (ترخيص حر) للترجمة المدمجة.
`sharp-libvips` المرافقة لـNext.js بترخيص LGPL وترتبط ديناميكيًا، وهذا مسموح تجاريًا. الخط IBM Plex Sans Arabic بترخيص OFL.
